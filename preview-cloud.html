Capability composition

MetaHaus Cloud defines how reusable Engines and capabilities can be governed, evaluated and composed without implying that they are active in a runtime.

Engine RegistryEngine definitions, manifests and semantic versions establish governed capability identity.
CompatibilityDeclared capabilities and dependencies can be evaluated before composition.
Engine PacksDependency resolution provides evidence of how compatible capabilities can be assembled into reusable packs.
Runtime boundaryA registered Engine is not an executable runtime, a Pack is not a deployed capability, and a resolved dependency is not runtime activation.
